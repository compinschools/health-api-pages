Privacy Policy

Last updated: 23 September 2026

Overview

Alfred Personal Health Integration ("the application") is a private, single-user software tool built and operated solely for the personal use of its developer/owner. It is not a public product, has no public sign-up, and is not distributed to or used by any other individual or organisation.

What data we access

With explicit user consent via Google OAuth 2.0, the application accesses the following categories of data via the Google Health API and Google Fitness API, solely belonging to the single account holder:

  • Activity data (steps, distance, calories, active minutes, exercise sessions)
  • Sleep data
  • Heart rate data
  • Body metrics (weight, body composition)
  • Nutrition data
  • Other health metrics covered by granted Google Health API scopes

How data is used

Data retrieved is used exclusively to display personal health information back to the account holder within their own private assistant/dashboard application. Data is never sold, shared, rented, or disclosed to any third party, advertiser, or other individual.

Data storage

Data and access tokens are stored locally on infrastructure owned and controlled by the account holder. No data is transmitted to or stored on any third-party server operated by parties other than Google (as the API provider) and the account holder themselves.

Data retention and deletion

The account holder may revoke this application's access at any time via their Google Account permissions page. Upon revocation, the application immediately loses the ability to retrieve further data. Locally cached data can be deleted at any time by the account holder directly.

Contact

For any questions regarding this privacy policy, contact the account holder via the GitHub account compinschools.
